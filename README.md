# Miami Supermarket App

## About the Project

Miami Supermarket is an Android application developed using Java and XML in Android Studio.

The application allows users to select supermarket products, choose quantities, calculate prices, and generate a receipt.

## Features

* Product selection
* Quantity selection
* Automatic price calculation
* Receipt generation
* Simple and user-friendly interface

## Technologies Used

* Java
* XML
* Android Studio

## Installation

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or a physical Android device.
